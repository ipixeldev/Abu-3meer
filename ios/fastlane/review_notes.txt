2. Purpose and audience
ABU 3MEER is an Arabic/English football fan app for users aged 13+. It combines football information, videos, free predictions/questions, recognition-only XP rankings, notifications, and optional Members content. There is no paid entry, betting, wager, prize, or redeemable reward; XP has no monetary value.

4. External services
Apple/Google/Firebase Authentication provide sign-in. Firebase Cloud Messaging/APNs provide optional push. YouTube public feeds/profile data support public videos and optional verification of an existing channel membership against a staff-uploaded list. 7. In-App Purchase
Navigate: sign in > Members > View plans. The paywall shows title, duration, localized price, renewal terms, benefits, Restore, Terms, and Privacy.
- Ostoora3 (Ostoora3): one month.
- Ostoora3 Pro Max (Ostoora3_Pro_Max): one year.
Both unlock the same Members content and badge; only duration differs. Recognition benefits are 150 XP once on first activation, 50 XP per verified renewal, and 2× XP only for correct match-winner, first-goalscorer, and exact-score predictions. Rankings have no prizes.

Every purchase initiated in the iOS app uses Apple IAP. There is no external purchase link or call to action on iOS. A user who already independently holds an Abu 3meer YouTube channel membership may submit that user’s public channel-profile link to check the latest staff-supplied list for the same access. This check cannot buy, renew, cancel, or manage YouTube membership. Equivalent access is available through Apple IAP. Free features require no purchase.
