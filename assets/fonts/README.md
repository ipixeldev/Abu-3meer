# Bundled app fonts

These font files are bundled so typography never depends on a runtime network
request. They are sourced from the official
[Google Fonts repository](https://github.com/google/fonts) and distributed
under the SIL Open Font License included in `licenses/`.

- English: Inter with Barlow Condensed display text, Montserrat, Nunito Sans
- Arabic: Cairo, Tajawal, Noto Sans Arabic

Do not replace a font binary without also updating its matching license file.
